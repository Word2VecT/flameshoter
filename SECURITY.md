# Flameshoter security

Security fixes target the latest Flameshoter release and master. Report vulnerabilities through the repository's private reporting channel at https://github.com/Word2VecT/flameshoter/security when available. Include a reproducible example and affected versions without posting private screenshots, credentials or signing keys in public issues.

Screenshots are processed locally. Screen Recording is managed by macOS; the application does not bypass TCC. The tap does not remove quarantine or disable Gatekeeper. Official releases currently use a fixed self-signed certificate and are not Apple notarized.

Default redaction replaces the interior with colors sampled outside the region. Traditional pixelation is optional and can retain information. Review the exported image before sharing sensitive material.
