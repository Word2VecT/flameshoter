# PixPin 功能对照与离线实现范围

对照日期：2026-11-12。参考 [PixPin 官网](https://pixpin.com/zh-hans/)、[功能列表](https://pixpin.com/zh-hans/features/)及其使用文档。该表描述 Flameshoter 当前代码的实际能力，不表示两个产品在识别质量、平台范围或所有操作细节上等同。

开发原则：优先在本机处理截图，不接入云端模型。以下“已有”指本次开发前已存在，“新增”指本次补充，“部分”表示仍有明确差异。

## 功能覆盖

| PixPin 能力 | Flameshoter 状态 | 实现与边界 |
| --- | --- | --- |
| 区域、多屏、延时截图，窗口 / 元素识别 | 已有 | ScreenCaptureKit 截图；元素识别需辅助功能权限。支持刷新画面并保留选区和标注。 |
| 像素定位、取色、选区历史 | 已有 | 鼠标附近放大预览、多种颜色格式、按显示器保存选区历史。 |
| 截图历史重新编辑 | 已有 | 原图与可编辑标注分开存储；可关闭历史或清除。 |
| 画笔、形状、箭头、文字、序号、马赛克 | 已有 | 支持选择、调整、图层排序、撤销 / 重做；默认遮挡使用周围颜色。 |
| 折线 | 新增 | 逐点点击，双击 / Return 完成，Backspace 删除顶点，Esc 放弃；一次撤销。 |
| 聚光灯 | 新增 | 保留矩形内画面，压暗外部，可调不透明度。 |
| 放大镜标注 | 新增 | 放大区域中心内容，倍率 1.25–8 倍，预览与导出共用渲染。 |
| 水印 | 新增 | 指定矩形内平铺文字，可调颜色、字号和不透明度。 |
| 自动马赛克 / 打码 | 新增，部分 | 本地 Vision 识别邮箱、电话、URL / IP、人脸和常见凭据标签；每处遮挡可修改。昵称、实体地址、所有密钥格式尚未覆盖，OCR 也可能漏识别。 |
| 智能擦除、背景补全 | 未支持 | 当前遮挡仅取样外侧颜色，不能重建纹理、对象后方背景。 |
| 剪贴板图片、文字、颜色、文件贴图 | 已有 | 包含 GIF / WebP 动图、缩放、透明度、置顶及关闭历史恢复。 |
| 贴图旋转、水平翻转、锁定、双击关闭 | 新增 | 静态图支持无损直角旋转与翻转；锁定限制移动、缩放和变换。动画帧暂未提供旋转 / 翻转。 |
| 贴图再次标注 | 新增 | Space 或右键菜单进入编辑，Return 创建新贴图，取消返回原图。原贴图留在关闭历史中。 |
| 贴图划选文字 | 已有，部分 | VisionKit 划选、复制；未实现 PixPin 的按 OCR 文字范围高亮、波浪线、删除线工具。可用普通标注工具手动标记。 |
| 文字识别 | 已有 | 本地 Vision，多语言由 macOS 支持范围决定，可校对、复制、导出文字文档。 |
| 二维码、工业条码 | 新增条码支持 | 使用 Vision 支持的全部码制，包括 Code 128 等；截图与贴图均有入口。实际可识别码制由系统决定。 |
| 截图翻译与译图 | 已有，部分 | macOS 本地翻译、编辑原文 / 译文、译图；部分语言首次需下载系统语言包。未接入大模型 AI 翻译。 |
| 图片转 Excel / CSV | 已有，部分 | 本地表格识别、单元格编辑、排序和行列调整，Excel 保留识别出的合并单元格；复杂无框线、手写和嵌套表格识别质量仍有限。 |
| 文档识别、Word 导出 | 新增，部分 | 本地文档识别，校对后导出 DOCX / RTF / TXT / MD。当前为可编辑文本段落，不还原字体、图片、复杂多栏、嵌套表格和公式结构。MD 导出为文本，不自动生成结构化标题或表格。 |
| 数学公式转 LaTeX | 未支持 | 需要独立公式结构识别模型；普通 OCR 结果不能视为等价 LaTeX。 |
| 纵向 / 横向长截图 | 已有 | 自动拼接、自动滚动、预览、手动裁剪、反向滚动自动裁剪、复制 / 保存 / 贴图。没有认证达到 PixPin 宣称的 200 万像素长图上限。 |
| 区域录屏，MP4 / GIF / WebP，暂停 / 剪辑 | 已有 | 帧率、延时、指针、系统音频和麦克风选项；录制结束后预览、修剪。 |
| 录屏鼠标点击、键盘提示 | 新增，部分 | 系统点击高亮；显示快捷键、导航和功能键。默认跳过普通文字、安全输入，不记录完整键盘文字或鼠标轨迹。键盘提示需输入监控权限。 |
| 摄像头画中画录屏 | 新增 | 选区右下角叠加默认摄像头，启用时才申请权限；暂停、取消、失败或停止时关闭摄像头。位置、形状、设备选择尚不可定制。 |
| 图片保存为 PDF / AVIF 等 | 已有 | PNG、JPEG、TIFF、BMP、无损 WebP、PDF、系统支持时的 AVIF。 |
| 实时导出预览 | 新增 | 保存对话框中原图 / 编码结果对照、尺寸、真实文件大小，JPEG / AVIF 质量滑块；快速切换时丢弃旧预览，保存使用当前匹配的编码字节。 |
| 自定义快捷键、鼠标映射、脚本动作 | 部分 | 已有快捷键设置和 CLI；任意鼠标动作映射、内置脚本动作编辑器尚未实现。 |
| 配置导入导出、云端同步 | 部分 | 已有 JSON / INI 导入导出；没有账号、云端备份、冲突合并或跨设备同步。 |
| 多平台、多界面语言 | 部分 | 当前为 Apple Silicon、macOS 26+，界面支持简体中文 / 英文；没有 Windows 版本及另外七种 PixPin 界面语言。 |

## 需要模型或服务的明确缺口

| 缺口 | 离线优先的下一步 | 若采用在线服务，需要什么 |
| --- | --- | --- |
| 公式 → LaTeX | 选择许可允许分发的本地公式模型，转换 Core ML，建立分式、积分、矩阵、手写等评测集，提供模型下载与资源预算。 | 明确公式识别接口、授权与费用、隐私说明、失败重试及结果校对。 |
| 智能擦除 | 引入本地内容感知修补 / 图像补全模型，提供画笔遮罩、预览、撤销和质量评测。 | 图像补全接口、图片上传授权、配额与超时处理。 |
| 大模型 AI 翻译 | 在现有系统翻译之外选择可分发的本地多语言模型，验证语言覆盖、内存、术语和版式。 | 服务提供商、API 凭据安全保存、费用、数据处理规则；不能静默上传截图。 |
| 文档版式 / 公式还原 | 本地版面分析、表格 / 公式结构提取和 DOCX 版面生成；评测多栏、书页、混合语言及手写内容。 | 文档识别接口及版式输出约定、上传授权、校对流程。 |
| 云端配置同步 | 先设计可选择的本地文件同步目录与版本 / 冲突策略；云同步另行接入。 | 用户选定同步服务、身份认证、配置数据范围、加密、冲突与退出清理规则。 |

上述能力本次没有创建占位菜单，也没有把普通 OCR、纯色遮挡或配置文件导出包装成完整的模型 / 云端功能。

## 使用与数据保留

- 新工具默认快捷键：V 折线、O 聚光灯、E 放大镜、W 水印、Shift+B 自动打码、Option+D 文档识别。配置迁移到 schema 13；与用户已有快捷键冲突时，新工具保持未分配状态。
- 贴图 L 锁定，Space 重新标注；右键菜单提供旋转、翻转、识别、翻译和导出。
- 自动打码完成后仍需核对。截图历史保留打码前的原图，撤销也能恢复原内容；需要删除原图时应关闭历史记录并清除历史。最终导出的图片包含已渲染的遮挡。
- 摄像头和键盘提示默认关闭，仅用户启用时请求相应权限。识别与图像处理在本机进行。

## 验证范围

新增自动测试覆盖效果像素与裁剪一致性、折线完成 / 取消 / 撤销、本地邮箱识别的字符级遮挡、文档中英文导出、Code 128、贴图变换与存档兼容、录屏键盘过滤与点击配置、设置迁移、异步预览防过期和工具弹窗大小 / 层级。小贴图和浅横幅使用独立编辑画布，测试确认工具可达且导出像素与原图一致。

在开发机上检查原生截图、工具参数、文档识别和导出预览；本地开发 ZIP 使用 ad-hoc 签名。摄像头与输入监控的权限流程、完整硬件录制、多显示器录制叠加、macOS 26 运行及全面辅助技术交互仍需发布前资格验证。
