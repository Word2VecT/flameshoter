# Flameshoter 0.3.11

Extract text from screenshots and pinned images offline with the bundled PP-OCRv6 Small detector and recognizer. The engine uses Metal on Apple Silicon and reuses the loaded models across selections. Copy the full result or a selected passage. Live Text remains available for selection on the original image.

Export recordings as animated PNG, refresh capture previews, translate screenshots locally, and edit recognized tables for spreadsheet export.

Recall prior capture regions for each display and choose how many regions to keep.

Record a selected region with configurable frame rate, delay, system audio and microphone. Pause and resume, preview and trim using native macOS controls, and export to MP4, GIF or lossless animated WebP. GIF and WebP do not include audio.

Pin clipboard images, GIF and animated WebP, text, colors and files. Restore open pins and closed pin history across restarts, including edited text and window placement.

Capture scrolling content vertically or horizontally with a live preview, crop and reverse-direction auto-crop. Automatic scrolling requires Accessibility access.

Copy pixel colors in common formats, and save captures as PDF or AVIF. Recognize text and QR codes locally from captures and pinned images, and select text with macOS Live Text.

Automatically select windows under the pointer, or detect interface elements with macOS Accessibility access. Choose the detection mode in Settings or drag to select an arbitrary region.
