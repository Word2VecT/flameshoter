基于 Flameshot 的原生 macOS 液态玻璃截图工具，支持简体中文和英文。

- 原生 Liquid Glass 标注工具栏与工具设置面板。
- 七页完整设置，含工具栏自定义、颜色预设、全量快捷键和配置导入导出。
- Apple Icon Composer 分层火焰图标，使用 Apple 资产编译器构建，支持系统外观。
- 保留 Flameshot 的截图、标注、撤销、复制、保存与置顶核心。

初始发布包支持 Apple Silicon，最低 macOS 26。包内包含 Qt，无需另装 Qt。

使用 ad hoc 签名，尚未经过 Apple 公证。首次打开可能需要在系统设置中允许；首次截图需要屏幕录制权限。

Homebrew: `brew install --cask Word2VecT/tap/flameshoter`

完整源代码及第三方许可见仓库。Linux、Windows 与 Intel 版本尚未作为本次发布包验证。
