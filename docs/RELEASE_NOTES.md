# Flameshoter 0.2.6

Removes the startup launcher window and its menu and CLI entries. Opening or reopening the app keeps it in the menu bar; capture and settings remain available from there. Capture failures no longer open a launcher window.

Share now uses a plain localized tool name and the default shortcut Command-Shift-S, so its tooltip follows the same name-and-shortcut format as other tools. Existing custom or explicitly cleared bindings are respected.

Rewrites both READMEs around installation, essential usage and licensing.
