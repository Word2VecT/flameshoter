# Flameshoter 0.3.1

Capture scrolling content vertically or horizontally with a live preview, crop and reverse-direction auto-crop. Automatic scrolling requires Accessibility access.

Copy pixel colors in common formats, and save captures as PDF or AVIF. Recognize text and QR codes locally from captures and pinned images, and select text with macOS Live Text.

Automatically select windows under the pointer, or detect interface elements with macOS Accessibility access. Choose the detection mode in Settings or drag to select an arbitrary region.
