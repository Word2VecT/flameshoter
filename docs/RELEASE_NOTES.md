# Flameshoter 0.2.4

Capture tools appear directly around the selection, following the original Flameshot macOS tool list and ButtonHandler placement algorithm. This includes blocked screen edges, corner allocation, virtual minimum selections, expanding rings and the inside fallback. Button size follows the original font line-spacing rule. Tool Settings stays at the left screen edge, and right-clicking an annotation tool selects it and opens its settings. Buttons and glass materials remain native AppKit components.

Settings use compact groups and multiple columns for application options, capture tools and color presets. Ordinary buttons keep their natural width. The window fits the selected page, with scrolling for longer pages.

Validation includes exact coordinate comparisons with 20 cases generated by the original C++ ButtonHandler using Qt, plus native control interaction, both interface languages and all seven settings pages. The application and its test runner retain no Qt dependency.

Retains the selection crash fix, original menu-bar icon, menu-bar residency and fixed signing identity from 0.2.3.
