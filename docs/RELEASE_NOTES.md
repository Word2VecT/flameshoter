初始发布包支持 Apple Silicon，最低 macOS 26。包内包含 Qt，无需另装 Qt。

使用 ad hoc 签名，尚未经过 Apple 公证。首次打开可能需要在系统设置中允许；首次截图需要屏幕录制权限。临时签名在更新后可能需要重新授权；若系统开关已开启仍失败，使用“设置 → 截图 → 修复屏幕录制授权…”。该操作只重建此应用的录屏授权，需要在系统提示中重新允许。跨版本保留授权需要稳定的 Developer ID 签名。
