# Provenance and platform components

Flameshoter is a GPL-3.0-or-later derivative of [Flameshot](https://github.com/flameshot-org/flameshot), initially based on commit `da34dcb1b296bd2e3bc589767abbe788084215ae`. Flameshot was created by Alejandro Sirgo Rica and its contributors. The three flame vector paths in the Icon Composer document derive from Flameshot's `data/img/app/org.flameshot.Flameshot.svg` under the Free Art License 1.3. The original artwork is credited to the Flameshot project and contributors; its source is preserved as packaging/macos/icon-layers/upstream-logo.svg. Flameshoter's 2026 adaptation removes the purple backing and separates the flames into Apple Icon Composer material layers. The original menu-bar mask is also retained in Resources/MenuBarIcon@2x.png, with its SVG source in packaging/macos/icon-layers/menubar-mask.svg. The adapted logo and original menu-bar mask remain under FAL 1.3; its license is included in licenses/FlameshotLogo-FAL-1.3.txt.

Version 0.2.0 replaces the C++ / Qt implementation with Swift and public macOS frameworks. Qt, Qt Color Widgets, KDSingleApplication and QHotkey are no longer built, linked or distributed. Earlier source and notices are recoverable from Git history, including commit `3ddd2b1` before the native migration.

The native application has no external Swift packages or bundled third-party frameworks. It uses Apple AppKit, ScreenCaptureKit, Core Graphics, Core Image, ImageIO, Carbon HotKey, ServiceManagement and UserNotifications. Apple frameworks, SF Symbols, Icon Composer and the asset compiler remain governed by Apple's terms; development tools are not redistributed with the application.

The complete release source and build scripts are available at https://github.com/Word2VecT/flameshoter. See LICENSE for GPL-3.0-or-later terms.
